# Tab 5: 原料管理 — 用户体验故事

## 故事 1: 浏览和筛选原料

**角色**: 仓库管理员 — 赵姐

**场景**: 赵姐需要查看当前所有在库原料的状态。

**用户故事**:
作为仓库管理员，赵姐希望快速了解原料总数和已上线/已下线的分布情况，并能按条件筛选找到特定原料。

**流程**:
1. 赵姐打开"原料管理" Tab，顶部 4 个指标卡片一目了然：原料总数、已上线、已下线、类别数。
2. 她看到原料列表按编码顺序排列，包含名称、类别、单价、单位、状态等关键信息。
3. 她想只看"调味酱"类别，在筛选表单中选择"调味酱"并点击"应用筛选"。
4. 表格立即只显示调味酱类别的原料。
5. 她想进一步找"榛子"相关的原料，在搜索框输入"榛子"并应用筛选。
6. 表格过滤出名称包含"榛子"的调味酱原料。
7. 她想看所有已下线的原料，在状态下拉选择"下线"。

**成功标志**: 通过组合过滤条件，赵姐能快速定位到需要的原料。

## 故事 2: 新增原料

**角色**: 产品开发工程师 — 小陈

**场景**: 研发部门新采购了一款"椰子脆片"，小陈需要将其录入系统。

**用户故事**:
作为产品开发工程师，小陈希望将新原料录入系统，编码自动生成、必填字段校验完善。

**流程**:
1. 小陈在"操作"区域选择"➕ 新增原料"。
2. 编码字段自动生成 `RM` + 4 位数字（如 `RM0012`），显示为禁用状态。
3. 他填写：
   - 名称: "椰子脆片"
   - 类别: 选择"调味酱"
   - 单位: "克"
   - 单位量: 输入 1000（每包 1000g）
   - 加价前单价: 输入 25.0000
   - 加价后单价: 输入 28.5000
   - 品项类型: 选择"普通"
   - 状态: 选择"上线"
4. 点击"保存"。
5. 系统校验必填项通过后调用 API 创建记录，显示"已新增: 椰子脆片 (RM0012)"并刷新页面。
6. 新原料出现在原料列表中。

**异常路径**:
- 若名称/类别/单位/单价/单位量为空，系统提示"请填写以下必填字段: 名称, 类别, ..."。

**成功标志**: 新原料出现在列表中，编码正确，数据完整。

## 故事 3: 修改原料

**角色**: 采购员 — 周姐

**场景**: 供应商通知"榛子巧克力"的采购价从 35 元调整到 38 元，周姐需要更新系统中的价格。

**用户故事**:
作为采购员，周姐希望快速找到原料并更新其价格。

**流程**:
1. 周姐在"操作"区域选择"✏️ 修改原料"。
2. 她在下拉菜单中选择"榛子巧克力"。
3. 表单自动填充该原料的全部字段，包括当前价格 35.0000。
4. 她将"加价后单价"从 35.0000 改为 38.0000。
5. 更新"加价前单价"从 32.0000 改为 34.5000（供应商提到出厂价也调整了）。
6. 点击"保存修改"。
7. 系统调用更新 API，显示"已更新: 榛子巧克力"并刷新页面。
8. 原料表中的价格已更新。

**成功标志**: 原料价格更新成功，刷新后数据正确。

## 故事 4: 删除原料

**角色**: 采购员 — 周姐

**场景**: "草莓酱"已停用且不再采购，周姐需要从系统中删除此条目。

**用户故事**:
作为采购员，周姐希望安全地删除不再使用的原料，避免误操作。

**流程**:
1. 周姐进入修改模式，选择"草莓酱"。
2. 滚动到表单下方，点击"🗑️ 删除此原料"按钮。
3. 系统显示警告信息："确认删除「草莓酱」？此操作不可撤销。"
4. 确认按钮"确认删除"和"取消"按钮同时出现。
5. 她点击"确认删除"。
6. 系统调用删除 API，显示"已删除: 草莓酱"并刷新页面。
7. 原料列表不再包含该条目。

**取消路径**:
若点击"取消"，系统清除确认状态，页面恢复正常，不做任何删除。

**成功标志**: 原料从系统中安全删除。

---

## 故事 5: Excel 批量同步

**角色**: 运营主管 — 小王

**场景**: 总部更新了 Excel 中的原料主数据表，小王需要将这些更新批量同步到系统中。

**用户故事**:
作为运营主管，小王希望通过 Excel 文件一次性同步大批量原料数据，避免逐条手动修改。

**流程**:
1. 小王展开"📤 上传原料表（Excel）"区域。
2. 他上传总部提供的"品项导出.xlsx"文件。
3. 在同区域上传"加价规则.xlsx"文件。
4. 系统自动预览差异，显示一个 DataFrame 表格，包含每条记录的预期操作（新增/更新/跳过）和差异对比。
5. 小王核对数据无误后，点击"确认执行同步"。
6. 系统执行批量同步，显示"同步完成: 新增 5, 更新 12, 跳过 3"。
7. 页面刷新，原料列表反映出最新的数据状态。

**异常路径**:
- 若只上传了一个文件，系统提示"请同时上传「品项导出」和「加价规则导出」两个文件后再预览同步。"

**成功标志**: 对比数据一目了然，执行后原料列表与 Excel 数据一致。
