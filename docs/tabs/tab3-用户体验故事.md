# Tab3: 原料价格模拟器 — 用户体验故事

## 核心故事

**作为** 产品经理
**我想要** 调整配料价格并即时查看对 SKU 利润的影响
**以便于** 在调价前做出数据驱动的决策

## 流程

1. 选择产品 → 系统加载 SKU 列表
2. 选择 SKU → 配方展开
3. 调整任一配料价格 → KPI 实时更新
4. 调整售价 → 毛利率即时重算
5. 满意后保存为场景 → 可预览/应用/对比

## 场景管理

- **保存场景**：输入名称 → Save → 存入 ScenarioStore
- **预览影响**：展开场景卡片 → Preview impact → 显示变更前后对比
- **应用到数据库**：Apply → 确认 → 写入 Supabase raw_materials
- **回滚**：在历史列表中点 Rollback → 恢复原价
- **对比**：选两个场景 → Compare → 显示差异

## 边界情况

- 所有配料价格为原始值 → Save 按钮无变化可保存
- 场景已全部回滚 → 状态显示 rolled back
- 无场景 → 场景对比区域不显示
