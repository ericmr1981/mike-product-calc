# Tab 8: 门店库存 — 用户体验故事

## 用户故事列表

### US-8-01：查看库存总览

**角色**：门店运营 / 店长

**需求**：我打开门店库存页，希望一眼看清当前库存的整体状况。

**流程**：

1. 进入"门店库存"页
2. 页面自动加载最新盘点数据（优先）或库存快照
3. 看到数据来源说明，如"数据来源：最新盘点 (2026-05-28T10:00:00)"
4. KPI Row1 展示：总品项 156 | 缺货 3 | 低库存 12 | 异常 1
5. KPI Row2 展示：库存总额 ¥28.5万 | 原料/包材 ¥22.3万 | 工具 ¥6.2万
6. KPI Row3 展示：消耗总额 ¥3.2万 | 日均消耗额 ¥1,067.00 | 消耗品项数 18 / 45 | 消耗最快 牛奶瓶 - 12.5/天
7. 下方表格列出所有品项的库存明细

**验收标准**：

- 数据加载成功后自动展示所有 KPI
- 数据来源文案正确（盘点 / 快照 / 无数据）
- 快照超过 2 小时显示黄色警告

---

### US-8-02：筛选库存

**角色**：店长

**需求**：我只想看 A 仓库中低于安全库存的原料，方便安排补货。

**流程**：

1. 在筛选表单中，仓库选择"A仓库"
2. 安全状态选择"低于安全库存"
3. 关键字输入"奶"
4. 点击「应用筛选」
5. 表格仅显示符合条件的品项，KPI 同步更新

**验收标准**：

- 筛选条件支持组合（仓库 + 品类 + 安全状态 + 关键字）
- 筛选"应用筛选"按钮触发，非实时筛选（避免频繁 rerun）
- 筛选后 KPI 基于过滤后的数据重新计算
- 仓库下拉显示可读名称（如"A仓库(WH01)"）

---

### US-8-03：设置安全库存

**角色**：运营主管

**需求**：我想为所有原料设置安全库存值，低于此值的品项会标记提醒。

**流程**：

1. 展开「安全库存设置」折叠面板
2. 表格显示所有品项的当前库存和可编辑的"安全库存"列
3. 将"牛奶"的安全库存设为 50，"奶油"设为 30
4. 点击「保存安全库存设置」
5. 回到主表格，available_qty < 安全库存的行显示黄色背景

**验收标准**：

- 安全库存设置持久化在 session_state（页面刷新前有效）
- 品项编码和名称列禁用编辑，仅安全库存列可编辑
- 安全库存为 0 表示不监控该品项
- 保存后库存表的 `safety_status` 列立即更新

---

### US-8-04：没有盘点数据时的体验

**角色**：首次使用用户

**需求**：系统还没有盘点数据，但我希望看到库存快照信息。

**流程**：

1. 进入库存页
2. 后端尝试 `list_latest_check_items()` 返回空
3. 自动回退到 `list_latest_inventory_rows()`（快照视图）
4. 页面正常显示，数据来源标注为快照
5. 如果快照也不存在，显示 `st.info("暂无库存快照数据")`

**验收标准**：

- 盘点数据优先，快照数据回退
- 回退过程对用户透明，不需手动切换
- Supabase 404 错误时显示引导信息（需执行 schema SQL）

---

### US-8-05：消耗分析

**角色**：采购经理

**需求**：我想查看上个月的物料消耗情况，了解哪些物料消耗最快。

**流程**：

1. 展开「消耗分析」折叠面板
2. 默认日期范围设为当月
3. 点击「查询」
4. 数据加载后显示：统计区间：30天 | 匹配品项：45项 | 新品项：3项
5. 表格按消耗量降序列出所有品项
6. 消耗最快的品项显示红色（urgent）、黄色（warning）背景

**验收标准**：

- 日期范围默认取盘点批次起止时间
- 品项可按消耗量、消耗金额、日均消耗、品项名称排序
- 可按品类筛选
- 新品项（仅期末有数据）排在最下方，消耗字段显示 "-"
- 预计耗尽少于 3 天红色标记，3-7 天黄色标记

### US-8-06：到货录入

**角色**：仓库管理员

*（注：到货录入功能在 inventory_upload.py 中，作为独立的 CLI/上传工具存在，不在 tab8 UI 中直接呈现。此处记录以便数据流转理解。）*

**流程**：

1. 准备到货 Excel 文件（含品项编码、品项名称、数量等）
2. 通过上传入口导入系统
3. 数据写入 `inventory_delivery_batches` + `inventory_delivery_items`
4. 下次消耗查询时自动纳入到货量计算
