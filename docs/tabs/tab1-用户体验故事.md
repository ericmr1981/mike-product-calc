# Tab1: 概览/校验 — 用户体验故事

## 用户故事

**作为** 门店运营人员
**我想要** 一打开系统就能看到整体数据健康状况
**以便于** 快速判断是否需要关注异常

## 流程

1. 用户登录后默认进入 Tab1
2. 页面自动加载所有数据源
3. 风险卡片的颜色让用户一眼识别严重程度
4. 业务指标区显示原料/产品/规格的总量
5. 建议操作区给出下一步行动指引（如"去 Tab8 查看缺货项"）

## 关键路径

- 正常状态 → 浏览概览 → 进入其他 Tab
- 缺货异常 → 红色警告 → 点击操作链接 → 跳转到对应 Tab

## 边界情况

- 库存快照未配置：显示空白状态，不报错
- 数据加载失败：st.error 提示，不影响其他页面
