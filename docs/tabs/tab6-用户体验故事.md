# Tab 6: 配方管理 — 用户体验故事

## 故事 1: 浏览产品配方

**角色**: 产品开发工程师 — 小陈

**场景**: 小陈需要查看"木姜子甜橙 2.0"的完整配方，确认配料组成和用量。

**用户故事**:
作为产品开发工程师，小陈希望通过选择产品快速查看其配方明细。

**流程**:
1. 小陈打开"配方管理" Tab，看到左右两栏布局。
2. 左栏显示产品列表下拉框，展开后包含所有已创建产品。
3. 他在下拉菜单中选择"木姜子甜橙 2.0"。
4. 右栏立即显示该产品的详情和配方明细：
   - 产品信息表单：品名"木姜子甜橙"、版本"2.0"、品类"Gelato"、制作类型"门店调配"、状态"上线"、最终成品勾选。
   - 配方明细表：列出所有配料（来源为"原料"或"半成品"）、配料名称和用量。
5. 他核对配方表中每个配料的名称和用量是否正确。

**新增产品**:
如果小陈需要新建一个产品，他可以在左栏展开"➕ 新建产品"区域：
- 输入品名"橙花茉莉 1.0"（版本号会自动拆分）。
- 选择品类"Sorbet"、制作类型"门店调配"、勾选最终成品。
- 点击"保存"，产品立即出现在下拉列表中。

**成功标志**: 产品配方信息完整展示，配料名称和用量一目了然。

---

## 故事 2: 编辑产品基本信息

**角色**: 运营主管 — 小王

**场景**: "海盐焦糖"的品类需要从"Gelato"改为"冰淇淋"，且其版本应升级为 2.0。

**用户故事**:
作为运营主管，小王希望直接修改产品的基本信息，无需重新创建产品。

**流程**:
1. 小王选择"海盐焦糖 1.0"，右栏显示产品信息表单。
2. 在表单中：
   - 将"版本"从 "1.0" 改为 "2.0"。
   - 将"品类"从 "Gelato" 改为 "冰淇淋"。
3. 点击"保存产品信息"。
4. 系统显示"产品信息已更新"并刷新页面。
5. 重新选择该产品，确认信息已更新。

**成功标志**: 产品信息在系统中成功更新，无需重新创建。

---

## 故事 3: 修改配方 BOM

**角色**: 产品开发工程师 — 小陈

**场景**: 小陈需要为"木姜子甜橙 2.0"添加一种新的配料"椰子脆片"，但发现误加了一条，需要删除。

**用户故事**:
作为产品开发工程师，小陈希望向现有配方中添加配料，并能撤销错误的添加。

**流程**:

### 添加配料
1. 小陈选择"木姜子甜橙 2.0"，在配方明细区域下方展开"➕ 添加配料"。
2. 他选择配料来源为"原料"。
3. 下拉菜单中出现所有原料列表，格式为"名称 (类别)"。
4. 他选择"椰子脆片 (调味酱)"。
5. 输入用量 "50.00"。
6. 点击"添加"。
7. 系统显示"配料已添加"并刷新页面。
8. 配方明细表中出现了新增的"椰子脆片"行。

### 添加半成品配料
如果是添加半成品作为配料：
1. 在添加配料时选择来源为"半成品"。
2. 下拉菜单显示其他产品的列表，格式为"品名 v版本"。
3. 可以选择某个半成品作为当前产品的配料。
4. 当前产品不会出现在选项中（防止自引用）。

### 删除配料
1. 小陈发现错误添加了"椰子脆片"。
2. 展开"🗑️ 删除单条配料"区域。
3. 下拉菜单显示"椰子脆片 (用量: 50.00)"。
4. 选择该配料，点击"确认删除"。
5. 系统显示"配料已删除"并刷新。
6. 配方明细表中已移除该配料，其余配料保持不变。

**成功标志**: 配料成功添加或删除，配方表中数据正确。

## 故事 4: 清空/导出配方

**角色**: 生产经理 — 老张

**场景**: 老张需要将"木姜子甜橙 2.0"的完整配方导出为 CSV 文件，以便线下分发给门店。

**用户故事**:
作为生产经理，老张希望快速导出配方数据，或彻底清空配方以便重新构建。

**流程**:

### 导出 CSV
1. 老张选择"木姜子甜橙 2.0"，查看配方明细。
2. 点击"📥 导出 CSV"按钮。
3. 浏览器下载名为"配方_木姜子甜橙 2.0.csv"的文件。
4. CSV 包含"来源"、"配料"、"用量"三列数据。

### 清空配方
如果老张需要完全重置配方：
1. 点击"🗑️ 清空全部配方"按钮。
2. 系统立即清空该产品的所有配方记录并刷新。
3. 配方明细表显示"暂无配方明细数据。"。
4. 随后可以通过"添加配料"功能重新构建配方。

**成功标志**: CSV 导出正确（包含所有配料行），或配方已成功清空。
